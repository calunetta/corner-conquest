- **Island sizing** (`LobbyBackground.layout.ts:25,28-32`): plan named two fixed px constants (`ISLAND_TILE_SIZE_PX`/`MONSTER_TILE_SIZE_PX`); shipped code uses one `ISLAND_WIDTH_PERCENT = 26` for all three islands, with `aspect-square` in `LobbyBackground.styles.ts:10`. Not a corner cut.
